# ✈️ AI-Powered Travel Planner

An AI-powered travel planning application built with **Python, LangChain, Google Gemini, Pydantic, and Streamlit**. The application generates personalized travel itineraries based on the user's destination, budget, trip duration, and interests.

## 📌 Project Overview

Planning a trip manually can be time-consuming because travelers need to research destinations, activities, food, accommodation, transportation, and estimated expenses.

This project uses **Generative AI** to simplify the process. Users provide their travel preferences, and the application generates a structured, personalized itinerary including:

* Destination overview
* Day-wise activities
* Food recommendations
* Hotel suggestions
* Estimated activity costs
* Budget breakdown
* Travel tips

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Travel-Planner.git
```

### 2. Navigate to the project folder

```bash
cd AI-Travel-Planner
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## 🔑 Gemini API Key

This project requires a **Google Gemini API key**.

Do not hard-code your API key inside the Python source code or commit it to GitHub.

For the Streamlit application, enter the API key through the application's sidebar.

For local development, you can also use an environment variable:

```bash
GOOGLE_API_KEY="your_api_key"
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
streamlit run ai_travel_streamlit.py
```

The application will open in your browser.

## 🧠 Pydantic Structured Output

The project uses Pydantic models to structure the response generated by Gemini.

The main models are:

```text
Activity
   ↓
DayPlan
   ↓
BudgetBreakdown
   ↓
TravelItinerary
```

This helps organize the generated response into predictable fields instead of displaying an unstructured text response.

## 🔗 LangChain Workflow

The application uses the following LangChain workflow:

```python
travel_chain = prompt | llm | parser
```

Where:

* `prompt` → Creates the travel planning prompt
* `llm` → Sends the request to Google Gemini
* `parser` → Converts the response into the Pydantic `TravelItinerary` structure
